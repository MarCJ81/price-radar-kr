# 🔍 깜깜이 시세 레이더 (얼마예요?)

정찰제가 아닌 서비스 — 차 수리, 집수리, 가전 청소, 치과 비급여, 이사·청소, PC·스마트폰 수리 — 의 **최저가·평균가·최고가**를 공개 자료 기준으로 조회하는 무서버 정적 웹앱입니다.

- 6업종 **54개 세부 품목**, 출처 **86곳** (공식 16 · 업체 공개 17 · 시장 집계 21)
- 함정 포인트 162개, 현장 질문 162문장
- 서버 없음 · 외부 CDN 0건 · 외부 전송 0건
- 모든 계산은 브라우저 안에서 (`core.js`)
- 개인정보 입력 없음, 견적 메모만 `localStorage`에 저장

## 기능

1. **통합 검색 + 업종 필터** — 이름·별칭·단위로 검색. 6업종 54개 세부 품목.
2. **조건별 실시간 재계산** — 지역(수도권/광역시/지방), 시간대(평일/야간·휴일), 차종(국산/수입), 자재 등급, 평수, 사다리차, 병원 규모, 기종 등. 적용된 보정을 전부 칩으로 보여줍니다.
3. **결과 카드** — 최저/평균/최고 + 레인지 바, 추가금 함정 3개, 현장 질문 3문장(복사), 출처·기준일·면책.
4. **견적 비교 메모장** — 업체 2~3곳 금액을 넣으면 평균 대비 %와 판정(저렴/적정/비쌈/최고가 초과), 최저 견적, 메모 복사. 새로고침해도 유지.
5. **실시간 검색 브리지** — DB에 없는 품목은 숫자를 만들지 않고, ① AI 조사 프롬프트 복사 + ChatGPT/Claude/Gemini 열기, ② 네이버 블로그·카페·영수증 후기 검색으로 연결합니다.
6. **JSON·CSV 내보내기** — 현재 검색·업종 필터에 걸린 품목을 조건 반영 밴드와 함께 내려받습니다. CSV는 UTF-8 BOM·CRLF로 엑셀에서 바로 열리고, JSON은 적용 조건(지역·시간대)과 생성 시각을 함께 담습니다. 파일은 브라우저에서 만들어지고 어디에도 업로드되지 않습니다.

## 데이터 원칙

`data.js`의 모든 항목은 `conf` 등급과 `sources`(이름·URL·기준일)를 가집니다.

- `official` — 정부·공공기관·협회·제조사 공식 자료 (심평원 2026 비급여, 공임나라 표준공임, 한국배관협회, Apple·삼성·LG 공식 수리비/출장비, 허가이사종합정보)
- `published` — 업체가 공개한 가격표 (영구크린, 홈닥터, 청연, 티벡스, 서울 바로하수구, 일산페인트 등)
- `market` — 실제 견적 집계·다출처 교차 (노하우카 2,817건, 숨고·크몽 2026 시세, PC공임 등)

평균은 자료가 밝힌 평균·중앙값을 우선하고, 범위만 있는 경우 **범위의 중간값**임을 `derive`에 명시했습니다. 확인되지 않은 항목은 넣지 않았습니다.
